Design System — ToolOptimizer CNC
00Marca

Apresentação e princípios

Fonte única de verdade visual do ToolOptimizer CNC. Cobre o que existe hoje no código, canoniza o que diverge entre implementações concorrentes, e registra propostas para o que ainda não existe. Escopo: app desktop, mobile, páginas públicas e admin (/admin).

Por que este documento existe

Antes dele, a mesma decisão visual tinha respostas diferentes em arquivos diferentes: 3 paletas de semáforo concorrentes, 2 tons de ciano, 5 estilos de modal, 4 variantes de slider. Este documento fixa uma resposta e nomeia as divergências como dívida — ver seção 02 para o primeiro caso mapeado.

Como ler os selos

Canon Decisão fechada — é assim que o produto deve ser, hoje ou como correção.
Proposto Derivado, ainda não implementado no código. Sugestão, não regra.
Dívida Existe no código, diverge do canônico. Vira trabalho futuro (seção 18).

Princípios

01
O sistema recomenda, o operador decideNenhum parâmetro é aplicado automaticamente — a interface sugere, o operador confirma. Disclaimer fixo em toda tela: src/components/disclaimer.tsx.
02
Segurança antes de estéticaO semáforo verde/amarelo/vermelho/bloqueado precede qualquer escolha visual. L/D > 6 é bloqueado, não apenas avisado.
03
HMI industrial, não dashboard genéricoFundo escuro, visor LCD, gauges, glassmorphism — a referência é painel de máquina, não SaaS.
04
Número é dado, texto é rótuloTodo valor numérico usa font-mono (JetBrains Mono); texto de interface usa Inter.
05
Uma fonte por decisão visualCor, espaçamento e componente têm exatamente uma resposta oficial — este documento é essa resposta.
Documento em construção — 4 sessões de execução (após a sessão 0 de registro do plano). Esta é a sessão 1: seções 00–02. As seções 03–19 chegam nas próximas sessões — ver plano em docs/plans/PLAN_DESIGN_SYSTEM_CANONICO.md.

Dívida visual

DívidaCiano duplicado. Token oficial #00D9FF (--color-primary) convive com rgba(0,229,255,.12) — equivalente a #00E5FF — na borda do visor LCD. Fonte: results-panel.tsx:226 e mobile-results-section.tsx:177.
Dívida#0f1419 escrito à mão. 36 ocorrências fora da definição do token, em 12 arquivos — incluindo 2 dentro do próprio index.css (body{}, ::-webkit-scrollbar-track). Deveria usar bg-background-dark ou var(--color-background-dark) em todos os casos.
Dívida3º sistema de semáforo, órfão. A função COLOR_PALETTES em gauge.tsx (componente não referenciado por nenhuma tela) deriva cor por percentual usando #39FF14 / #FFD700 / #E74C3C — incompatível com seg-* e com o grupo Gauge acima. Componente é candidato à remoção.

Tema claro — proposto

PropostoNão existe no produto — 100% derivado para esta proposta. Hue de marca, acentos, semáforo e gauge ficam invariantes entre temas; o toggle no topo troca apenas o fundo de referência (--dsx-bg) usado no cálculo de contraste abaixo. Tons que resultarem em FAIL ou AA18 servem para acento — ícone, borda, fundo com texto escuro por cima — não como texto pequeno direto. Variante "ink" escurecida para uso como texto fica em aberto para decisão futura.
Use o toggle "Escuro (canônico) / Claro (proposto)" no topo da página: os badges de contraste em Marca, Acentos, Semáforo e Gauge recalculam ao vivo contra o novo fundo.
