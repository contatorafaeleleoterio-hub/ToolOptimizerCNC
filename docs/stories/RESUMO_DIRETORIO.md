# Resumo de User Stories - Pasta /docs/stories

Esta pasta contém o detalhamento das Histórias de Usuário (User Stories), que traduzem requisitos de negócio e funcionalidades específicas do produto para o ciclo de desenvolvimento.

### Conteúdo:

* **story-007-candidates.md**: Lista e definição de funcionalidades candidatas a implementações futuras.
* **story-010-item10-sistema-de-favoritos.md**: Especificação técnica e funcional do sistema de persistência para salvar configurações de simulação favoritas do usuário.
* **story-011-item52-simulacao-cassino.md**: Detalhamento do design, interatividade e comportamento do modo de simulação visual estilo "cassino".
