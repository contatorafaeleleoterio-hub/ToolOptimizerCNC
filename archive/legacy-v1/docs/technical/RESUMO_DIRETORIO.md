# Resumo Técnico - Pasta /docs/technical

Esta pasta centraliza a fundamentação técnica e as regras de negócio do projeto, servindo como "manual de engenharia" para garantir a consistência com a teoria de usinagem e os padrões de arquitetura.

### Conteúdo:

* **ESPECIFICACAO_TECNICA_CONSOLIDADA.md**: Visão geral da arquitetura e decisões técnicas.
* **DADOS_TECNICOS_KIENZLE_E_VC.md**: Parâmetros físicos (fórmulas e constantes) de usinagem (força de corte, Kienzle).
* **PRD_Velocidades_Corte_CNC.md**: Especificação funcional dos cálculos de velocidade de corte.
* **CASOS_TESTE_REFERENCIA.md**: Exemplos práticos de entrada/saída para validar os cálculos do app.
* **padronizacao-adotada.md**: Convenções de código, estilos e diretrizes de desenvolvimento do projeto.
* **srctypes.md**: Definições de tipos de dados usados no código-fonte para garantir segurança.
