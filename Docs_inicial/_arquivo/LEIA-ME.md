# `_arquivo/` — isolado, não ler de rotina

Documento fechado: plano executado e já absorvido, relatório superado, dado bruto já incorporado a um
canônico. Nada aqui foi apagado do git — mover para cá é reversível a custo zero
(`git mv de volta`, ou `git log --follow` acha o histórico de qualquer arquivo, mesmo já
descartado). O ponto de existir é **não competir por atenção** com o documento vivo: um agente
começando sessão não varre esta pasta a menos que esteja procurando procedência de uma decisão antiga
ou o Mestre pedir explicitamente.

Se um documento de fora do projeto cita um caminho que não existe mais, ele provavelmente foi movido
para uma das três pastas abaixo — confira `../INDICE_DE_ARQUIVOS.md` antes de assumir que sumiu.

| Pasta | O quê |
|---|---|
| `planos/` | Plano de ação cujo resultado já está noutro documento — não serve mais como referência de trabalho. |
| `relatorios/` | Auditoria/relatório cujos achados já foram propagados e fechados. |
| `descarte/` | Material bruto de apoio (inventário, rascunho) — nunca foi fonte, só insumo já consumido. |
